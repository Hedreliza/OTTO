### Como testar o projeto

1. Clone este repositório para sua máquina.
2. Abra a pasta no VS Code com a extensão do **PlatformIO** instalada.
3. Se você estiver usando o Arduino UNO em vez do MEGA, mude a linha default_envs no arquivo platformio.ini para uno: 
```ini
   default_envs = uno
```
Use o código com cuidado.
4. Conecte sua placa via USB e clique no botão de **Upload** do PlatformIO.
